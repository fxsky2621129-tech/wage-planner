# 日給と時間の計画帳

「勤怠・改善基準チェッカー」とは別の、個人用の年間賃金・勤務計画シミュレーターです。外部ライブラリ・サーバー・アカウント・APIキーは不要です。スマホ、PCのブラウザーに対応し、条件はそのブラウザーの localStorage に保存します。入力内容を外部に送信しません。端末間同期はありません。

## すぐ使う

ダウンロードしたフォルダーの `index.html` をブラウザーで開くと使えます。スマホで使う場合はGitHub Pagesへ配置し、そのURLを開いてください。ブラウザーのメニューからホーム画面に追加できます。オフライン配信を行うPWAではありません。

初期値は日給19,000円、賃金予算418,000円／月、土日祝休み、8時間＋追加労働4時間＋休憩1時間です。会社休日・有給の日付は仮の値なので、必ず実際の予定に変更してください。年始1/1〜3も仮に追加しています。特別条項・拘束時間延長のチェックは初期状態ではオフです。

## 日々の実績を入力する

最大残業時間の下段には「割増なし」の比較を表示します。25%・50%の残業割増と深夜・休日の割増をすべて除外し、日給÷基礎時給−所定労働時間で逆算します。初期条件は7時間53分。選択月の計画上の出勤日数を掛けた追加労働と実労働の月末合計も表示します。これは割増を払わなくてよいという意味ではなく、実際の給与支払いや法令上の勤務可能時間に使用できない参考値です。

年間の計画指標の下に、月間の計画上の出勤・法定時間外・拘束時間も表示します。対象月は「月別の実績入力」の月選択と連動します。これらは左側の計画条件による数値で、入力した実績の合計は日別表の下に表示します。

「月別の実績入力」で月を選び、各日の始業・終業・休憩（分）を入力します。終業が翌日になる場合は「翌日」にチェックします。「深夜実労働」は22時〜翌5時の勤務から休憩を除いた時間数です。始業・終業だけでは深夜の休憩位置がわからないため、自動では差し引きません。

勤務区分は「勤務・休み・有給・法定休日勤務」。休日・有給の初期区分は左側の予定から読み込むため、実際の状況に変更してください。法定休日勤務は法定休日に働いた場合のみ選択します。祝日・土曜日だから自動的に法定休日になるわけではありません。

月末に実労働・拘束・法定時間外を集計し、60時間までの25%加算額と60時間超部分の50%加算額、それぞれの通常時給分込み残業代を表示します。60時間ちょうどは25%です。法定休日は別途35%加算し、60時間の集計から除きます。有給は実労働に数えません。月をまたぐ週の40時間超も入力済みの実績から計算します。

未入力の日は0時間扱いの途中集計です。週40時間超の正しい判定には前月分も含めて勤務をすべて入力してください。入力エラーの行は集計に含めず、日付と原因を表示します。日をまたぐ勤務は始業日の月にまとめて計上します。24時間超の勤務や変形労働時間制には対応していません。

実績は端末のブラウザーに年ごとの日付で保存します。対象年を切り替えても過去の実績は保持します。「初期値に戻す」は計算条件だけを戻し、実績は削除しません。ブラウザーの保存データを消すと実績も失われます。CSVを定期的に保存してください。CSVは12か月の集計と日別実績を出力します（再読込機能はありません）。上部の最大残業時間・年間4指標は計画条件による試算で、実績集計とは別です。

## GitHubへの置き方

1. GitHubで新しいリポジトリ（例 `personal-wage-planner`）を作ります。既存の勤怠アプリとは別のリポジトリにします。
2. このフォルダーの**中身**をリポジトリ直下へ入れます。`.github` も含めます。ZIPそのものをアップロードするだけでは動きません。
3. リポジトリの **Settings → Pages → Source → GitHub Actions** を選びます。
4. `main` ブランチへ反映すると、付属のワークフローが計算テストを実行し、公開します。既にファイルを追加済みなら **Actions → Deploy to GitHub Pages → Run workflow** を実行できます。
5. Pagesに表示されるURLをスマホ・PCで開きます。

参考：[GitHub公式のワークフローによるPages公開手順](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)。

公開設定について：公開リポジトリではソースが公開されます。GitHub Pagesの閲覧URLにも認証は付けていません。非公開リポジトリのPages対応や公開範囲はGitHubの契約・組織設定に依存します。入力した条件はリポジトリへ保存されません。

Gitを使う場合は、このフォルダーで新しいリポジトリを初期化し、作成したリポジトリのURLを指定します。

```sh
git init
git add .
git commit -m "Add personal wage planner"
git branch -M main
git remote add origin https://github.com/YOUR_ACCOUNT/personal-wage-planner.git
git push -u origin main
```

ブランチ名が `main` 以外の場合は `.github/workflows/pages.yml` の対象ブランチを変更します。

## 入力と計算

- 残業込みモード：基礎時給を別に入力。必要な勤務賃金が「日給×出勤日」を上回る場合は差額を補填した支給見込みを表示します。
- 基本日給モード：基礎時給＝日給÷所定労働時間。追加労働と深夜の賃金を別途加算します。例えば19,000円÷8時間＝2,375円／時であり、最低賃金の1,195円を残業単価の基礎として代用しません。
- 通常の労働時間制、月曜起算の週、暦年・暦月集計。1日8時間・週40時間超の法定時間外を重複なく集計します。1月1日の週の前年分の法定内労働は専用欄に入力します。
- 月60時間までの法定時間外は25%、超過部分は50%の加算。深夜はさらに25%を加算します。上部の計画は休日に勤務しない前提で、日別実績では休日の区分を変更できます。
- 有給は支給額を別入力し、実労働・残業・拘束には数えません。休日と重なる有給日・重複日付は二重に数えません。
- 2026・2027年の国民の祝日と休日を収録。会社休日は日付で設定し、重複を除外します。翌年以降を追加する場合は `engine.js` の祝日と `index.html` の対象年を更新してください。
- 「予算内残業」は賃金のみで逆算した法定時間外の月合計。法令による勤務可能時間ではありません。
- 画面上部は「日給以内での1日の最大残業時間」を表示します。毎日同じ追加労働時間とし、月60時間超の50%割増を日付順に割り当て、**各出勤日**の必要賃金が日給以内となる上限を分単位で切り捨てます。月額平均で日給以内という計算ではありません。月の予算・拘束時間や36協定による上限はこの数値に適用していません。
- 初期条件では5時間15分、最も賃金が高い日の必要賃金は18,971円（表示切り上げ）。基本日給19,000円＋残業代モードの場合、総額19,000円以内で残業できる時間は0時間です。
- CSVはExcel向けUTF-8 BOM付き。支給額・不足分・法定時間外・拘束時間を出力します。

比較用最低賃金1,195円は愛知県の2026年10月1日適用額です。全月同額の計画比較として使用し、過去月の最低賃金を自動切り替えしません。基礎時給の変更があるときは期間を分けて確認してください。

## 判定の限界

このアプリは給与確定・法令遵守証明のシステムではありません。特別条項は臨時的な特別の事情がある場合の条件で、恒常的に年960時間働かせる許可ではありません。実際の協定上限がより低ければ、その上限を優先してください。

固定残業代の区分・有効性、賃金の各手当、有給賃金の算定方法、休息期間、運転時間、連続運転、法定休日の指定自体の適否、休日労働の回数、変形労働時間制、長距離運送の例外、暦年外の協定起算日、年をまたぐ拘束延長の連続月は判定しません。結果が範囲内でも全項目を満たす意味ではありません。

予算は**賃金のみ**です。会社負担社会保険料、賞与、通勤費、その他経費は含みません。待機・積込み・荷卸しを労働時間に含めて入力してください。円表示は切り上げ、内部は端数を保持します。CSVの予算差は安全側に切り捨てています。年間合計の端数処理と月表示合計は数円ずれることがあります。

## 開発・検証

Node.js 20以降で、依存関係をインストールせず実行できます。

```sh
npm test
npm start
```

プレビューは `http://127.0.0.1:4173`。画面 `index.html`、表示 `style.css`、UI `app.js`、計算 `engine.js`。テストは `tests/engine.test.cjs`。

### 実績入力の年月
「入力する月」で2026年10月〜2028年度末（2029年3月）の30か月を選択できます。初期表示は2026年10月。年月ごとに実績を保存し、月末合計・月間計画・比較用合計も選択年月に連動します。左側の対象年は年間計画用です。CSVは実績で選択した年の全12か月を出力します。会社休日・有給のMM-DD設定は各年に共通で適用されます。年をまたぐ週は前年末の入力済み実績を引き継ぎ、入力がない場合は設定した年初の週の時間を使用します。
2028・2029年の祝日は現行の祝日法と[国立天文台の春分・秋分予測](https://www.nao.ac.jp/faq/a0301.html)に基づく暫定日程です。正式公表後はengine.jsのholidaysを更新してください。

最大残業時間の右側には愛知県の地域別最低賃金（時間額1,195円、2026年10月1日適用）と公式資料リンクを表示しています。この公表額は左の比較用最低賃金入力とは独立した参考表示です。改定時はindex.htmlの表示額・適用日を更新してください。

GitHubへは非公開リポジトリとして保存しています。Pages配信は初期状態では無効です。配信する場合はPagesの利用条件と公開範囲を確認し、SourceをGitHub Actionsに設定後、Settings → Secrets and variables → Actions → VariablesでPAGES_ENABLED=trueを登録してワークフローを実行してください。
